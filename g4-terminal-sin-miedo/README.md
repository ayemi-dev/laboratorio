# La terminal sin miedo: diez comandos para empezar

Cuarto video de la serie **Herramientas de desarrollador** del Laboratorio Ayemi. Diez comandos para moverte en la terminal sin miedo, dos trucos para escribir menos y qué pasa cuando te equivocas.

## Los diez comandos del video

| Comando | Qué hace |
|---|---|
| `pwd` | Te dice en qué carpeta estás |
| `ls` | Muestra lo que hay en la carpeta |
| `mkdir respaldos` | Crea la carpeta `respaldos` |
| `cp index.html respaldos/` | Copia `index.html` dentro de `respaldos` |
| `cd respaldos` | Entra a la carpeta `respaldos` |
| `cd ..` | Regresa a la carpeta de arriba |
| `mv borrador.txt notas.txt` | Cambia el nombre (o mueve un archivo) |
| `rm notas.txt` | Borra el archivo; no pasa por la papelera |
| `clear` | Limpia la pantalla |
| `code .` | Abre la carpeta en Visual Studio Code |

La guía completa con cómo preparar la carpeta de práctica, dónde abrir la terminal en cada sistema, los dos trucos y el aviso sobre `rm` está en [`comandos.md`](comandos.md).
