# VS Code: el editor para empezar a programar

Primer video de la serie **Herramientas de desarrollador** del Laboratorio Ayemi. [Visual Studio Code](https://code.visualstudio.com/) es gratuito para uso personal o comercial y funciona en Windows, macOS y Linux. Su base, Code - OSS, es código abierto con licencia MIT; la versión que descargas de Microsoft le agrega algunas partes propias.

## Pruébalo sin instalar nada

Abre https://vscode.dev en tu navegador. Sirve para editar y explorar código; para correr, compilar o depurar, o para usar la terminal, instala la versión de escritorio.

## Los atajos del video

| Qué hace | Windows y Linux | macOS |
|---|---|---|
| Paleta de comandos: cualquier función, sin buscar en los menús | `Ctrl+Shift+P` | `⇧⌘P` |
| Abrir rápido un archivo escribiendo parte de su nombre | `Ctrl+P` | `⌘P` |
| Agregar la siguiente coincidencia de lo seleccionado (multicursor) | `Ctrl+D` | `⌘D` |
| Terminal integrada | ``Ctrl+` `` | ``⌃` `` |
| Control de código fuente (Git) | `Ctrl+Shift+G` | `⌃⇧G` |
| Ejecutar y depurar | `Ctrl+Shift+D` | `⇧⌘D` |
| Extensiones | `Ctrl+Shift+X` | `⇧⌘X` |

Con una distribución de teclado distinta a la de EE. UU. algún atajo puede cambiar: revísalos en *File > Preferences > Keyboard Shortcuts*.
