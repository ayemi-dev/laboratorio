# G5 · VS Code o Zed: ¿cuál usas tú?

Material de apoyo del video **VS Code o Zed: ¿cuál usas tú?** (Saga G · Herramientas de desarrollador).

En este video no se recomienda ninguno de los dos editores: se presentan lo que tienen en común, en qué se diferencian y cómo importar tu configuración si quieres probar Zed viniendo de VS Code.

## Contenido

- [`comparativa.md`](comparativa.md): tabla comparativa, comandos de la paleta de Zed (`zed: import vs code settings` y `zed: toggle base keymap selector`), requisitos y enlaces oficiales.

## Enlaces principales

- Visual Studio Code: https://code.visualstudio.com/
- Zed: https://zed.dev/
- Guía de migración de VS Code a Zed: https://zed.dev/docs/migrate/vs-code
