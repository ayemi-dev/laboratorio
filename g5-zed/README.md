# Zed: el editor que se presenta como el más rápido

Quinto video de la serie **Herramientas de desarrollador** del Laboratorio Ayemi. Qué es Zed, cómo instalarlo con un solo comando en Windows y Linux, y los atajos esenciales para empezar si vienes de Visual Studio Code.

## Instalación y atajos principales

| Comando o atajo | Qué hace |
|---|---|
| `winget install -e --id ZedIndustries.Zed` | Instala Zed en Windows desde PowerShell |
| `curl -f https://zed.dev/install.sh \| sh` | Instala Zed en Linux desde la terminal |
| `Ctrl+P` (Mac: `Cmd+P`) | Salta a cualquier archivo de tu carpeta |
| `Ctrl+Shift+P` (Mac: `Cmd+Shift+P`) | Abre la paleta de comandos |
| `Ctrl+O` (Mac: `Cmd+O`) | Abre una carpeta de trabajo |
| `Ctrl+,` (Mac: `Cmd+,`) | Abre los ajustes del editor |

La guía completa con cómo importar los ajustes de Visual Studio Code, cómo activar el modo Vim y los detalles de colaboración está en [`atajos.md`](atajos.md).
