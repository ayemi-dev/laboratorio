# Gracias: la guía de todo el Laboratorio

Pasamos los 100 seguidores en Instagram (el 20 de noviembre de 2026 somos 108). Gracias por ver, guardar y probar cada video. Esta guía junta todo lo que hemos publicado hasta hoy en el Laboratorio Ayemi: cada video tiene su carpeta con el código y la guía para que lo repitas tú.

Lo que viene: más Laboratorio, siempre con el código para descargar. ¿Qué tema quieres ver después? Cuéntanos en los comentarios de nuestro reel en Instagram ([@ayemidev](https://www.instagram.com/ayemidev/)).

Para bajar todo el código de una vez, mira [`comandos.md`](comandos.md).
