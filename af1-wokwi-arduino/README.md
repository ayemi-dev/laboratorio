# Simula un Arduino gratis en el navegador (Wokwi)

Aprende microcontroladores sin tener la placa: [Wokwi](https://wokwi.com/) simula un Arduino Uno (y otras placas) en tu navegador, sin instalar nada.

## Usar

1. Abre un proyecto nuevo con Arduino Uno: https://wokwi.com/projects/new/arduino-uno
2. Borra el código de ejemplo y pega el de [`sketch.ino`](sketch.ino).
3. Pulsa el botón verde de iniciar simulación: el LED integrado de la placa (marcado «L») parpadea cada medio segundo.

## Qué incluye el plan gratuito

Según la página de planes de Wokwi (verificado el 11 de noviembre de 2026): simulaciones ilimitadas, proyectos públicos ilimitados y Wi-Fi virtual. Los proyectos privados y algunas funciones avanzadas son de pago. Wokwi es gratuito para uso personal; para uso comercial revisa sus planes.

## Placas que simula

Arduino Uno, Nano y Mega; ESP32 (varias familias); Raspberry Pi Pico y Pico 2; y algunos STM32 (por ejemplo el STM32F103C8, «Blue Pill»). La lista completa, con sensores, pantallas y servos, está en la documentación.
